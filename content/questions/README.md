# Question banks

## Scoring

**personality.json** (48 items, 5-point scale). For each dimension (EI, SN, TF, JP), `sum = Σ key × (answer − 3)` over its 12 items, so `sum` runs from −24 to +24. The first letter's percentage is `50 + 50 × sum / 24` (E, S, T or J); the second letter gets the rest. Above 50% the first letter wins; exactly 50% is a tie, so the code needs a tie-break rule.

**mizaj.json** (24 items, one option each). `H = Σ h` and `M = Σ m` over the chosen options. Quadrant: `H ≥ 0, M ≥ 0` damvi; `H ≥ 0, M < 0` safravi; `H < 0, M ≥ 0` balghami; `H < 0, M < 0` saudavi. Strength on each axis is `|sum| / max`, where `max` is the largest total possible on that side: heat ±32, moisture ±26 (each axis is symmetric). Recompute these if items change.

**interests.json** (24 items, 3-point scale). Add the answers for each RIASEC code (4 items each, range 4–12). The three highest codes, in order, form the Holland code (e.g. "SAE"); decide how to break ties in code.
